# Pirâmide de testes com smoke E2E

O Tournamenter OBR terá testes unitários para regras de pontuação e algoritmos, testes de componentes para interações React e um smoke E2E pequeno contra o Tournamenter real do checkout. Chamadas ao Sistema Olimpo serão mockadas em CI para manter os testes reproduzíveis e sem dependência de credenciais externas.
